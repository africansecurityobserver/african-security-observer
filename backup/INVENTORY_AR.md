## معلومات يجب حفظها في مكان آمن منفصل

- [ ] الوصول إلى حساب GitHub ووسيلة استرداد الحساب.
- [ ] قيمة مفتاح `GEMINI_API_KEY` أو طريقة إصدار مفتاح بديل.
- [ ] أي مفاتيح أو اشتراكات تضاف لاحقًا.
- [ ] بيانات النطاق الخاص إذا اشتريته مستقبلًا، ومكان تسجيله وتجديده.
- [ ] تعليمات الاستضافة البديلة وبيانات الفوترة الضرورية.
