# المرصد الإفريقي للأمن والدفاع — حزمة مجانية أولية

## ماذا تفعل هذه النسخة؟
- واجهة عربية RTL مبنية على النموذج الأولي.
- سكربت يجلب بيانات العناوين والوصف والتاريخ والرابط من خلاصات RSS.
- تصنيف أولي بالكلمات المفتاحية وإزالة تكرار بسيطة.
- سير عمل GitHub Actions لتحديث ملف الأخبار كل ساعة عند تفعيله.

## قبل النشر
1. أنشئ مستودع GitHub عامًّا وارفع محتويات هذا المجلد إلى جذر المستودع.
2. راجع `config/feeds.json`: بعض المواقع تغيّر عناوين RSS أو شروطها؛ عطّل أي خلاصة لا تعمل أو لا تسمح شروطها باستخدام البيانات بهذه الطريقة.
3. في إعدادات المستودع، فعّل Actions، ثم من Settings → Pages اختر النشر من الفرع الرئيسي (main), المجلد /(root).
4. من تبويب Actions شغّل `Update news` يدويًا أول مرة. بعد ذلك يعمل الجدول كل ساعة، مع مراعاة قيود GitHub المجانية.

## ملاحظات مهمة
- لا يوجد ذكاء اصطناعي مدفوع أو ترجمة آلية في هذه النسخة. لا تُترجم العناوين تلقائيًا؛ تُعرض بلغة المصدر.
- التصنيف بالكلمات المفتاحية تجريبي وقد يخطئ. لا يُعد تحققًا صحفيًا ولا يميّز وحده بين الخبر المؤكد والادعاء.
- لا تُنسخ المقالات كاملة. يُحفظ العنوان والوصف المختصر والرابط إلى المصدر فقط. راجع شروط كل مصدر.
- هذه الحزمة لا تنشر الموقع نيابة عنك؛ رفعها إلى حساب GitHub وتفعيل Pages وActions خطوات مطلوبة من صاحب الحساب.
- GitHub Pages وActions لهما حدود وشروط استخدام؛ لا يمكن ضمان تشغيل غير محدود أو تحديث لحظي.
